# UI-2 產品資料設定

來源截圖：`doc/UI-ref/UI-2-產品資料設定.jpg`

## 用途

維護產品主檔、進價、售價、安全庫存與銷退單位。舊 DOS 版以全寬資料表呈現，底部顯示功能鍵。

## 畫面配置

```text

│ 2.    264. 1.  糯米腸         糯米腸      58.0     61.0    0.    1:1:1    │
```

## 欄位

| 畫面欄位 | 對應資料 | 說明 |
| --- | --- | --- |
| 序碼 | 顯示序號 | 畫面排序序號。 |
| 代碼 | `product.id` 或舊系統產品代碼 | 截圖顯示如 `145.`、`264.`。 |
| 車 | `product.car_number` | 數字欄位，截圖中常見 `0.` / `1.`。 |
| 詳細名稱 | `product.detailed_name` | 完整品名。 |
| 簡稱 | `product.short_name` | 訂單畫面使用的短品名。 |
| 進價 | `product.purchase_price` | 可含小數。 |
| 售價 | `product.sale_price` | 可含小數。 |
| 安存 | `product.safety_stock` | 安全庫存量。 |
| 銷退單位 | `product.return_unit` | 截圖格式類似 `1:1:1`，需保留字串表示。 |

## 操作

| 按鍵 | 行為 |
| --- | --- |
| 方向鍵 | 移動目前產品列。 |
| `F1` | 增加產品。 |
| `F3` | 移位，調整產品顯示順序。 |
| `F5` | 列印詳細表。 |
| `F6` | 列印報價單。 |
| `F9` | 刪除目前產品。 |
| `Esc` | 回主系統。 |

## 重現注意事項

- 截圖未顯示現行 spec 中的「常用」欄；常用產品若仍需保留，應視為資料邏輯，不放入此 DOS 主畫面第一版。
- `進價`、`售價`、`安存` 都以數字顯示，輸入時需做數字保護。
- `銷退單位` 在舊系統是可見欄位，不應省略。
