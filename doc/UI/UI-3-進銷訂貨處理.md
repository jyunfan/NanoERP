## 3.0 進入介面

進入「進銷訂貨處理」後，舊系統先顯示選單：

```text
3.進入介面
編輯客戶訂單、廠商進貨/退貨

作業日期 115年 4月 7日 星期二
0.回主系統  1.客戶訂單  2.廠商訂單
```

| 選項 | 行為 |
| --- | --- |
| `0` | 回主系統。 |
| `1` | 進入客戶訂單。 |
| `2` | 進入廠商進退貨。 |

## 3.1 客戶訂單

### 初始畫面

客戶訂單畫面由左側客戶清單與右側產品總數區構成；未進入資料時中央顯示操作提示。

```text
┌客戶__交易數_┐                         ┌產品__總數____┐
│             │     Tab : 左右切換      │              │
│             │     Enter : 選定        │              │
│             │     Esc : 跳出          │              │
└─────────────┘                         └──────────────┘
作業日期 115年 4月 7日 星期二
0.回上系統  1.其餘市場  2.建國市場  3.南部市場  4.總數核對
```

### 客戶清單

左側顯示當前市場客戶與交易數。

| 欄位 | 說明 |
| --- | --- |
| 客戶 | 客戶名稱。 |
| 交易數 | 該客戶當日有數量的訂單筆數或交易數；無交易時空白。 |

### 訂單明細模式

選定客戶後，中間以三欄群組顯示產品名稱與數量。

```text
┌客戶__交易數_┐  ┌名稱__ 數量_____ 名稱__ 數量_____ 名稱__ 數量_____┐
│ 徐素華      │  │ 小S包  10.      蘭干箱          軟素雞            │
│ 豆腐嫂      │  │ 小O包  12.      干片            萬大黑            │
│ 玉香行  1.  │  │ ...                                                   │
└─────────────┘  └───────────────────────────────────────────────────────┘
頁數: 1-0
總數 0.0    交易 0.
```

| 欄位 | 說明 |
| --- | --- |
| 名稱 | 產品簡稱；若旁邊顯示笑臉，表示該客戶最近 `RECENT_ORDER_DAYS` 天內曾訂購此產品，預設為 30 天。 |
| 數量 | 該客戶當日訂貨數量。 |

### 售價模式

在客戶訂單畫面按 `F3` 可進入售價/價格維護模式；再按一次 `F3` 回到訂單明細模式。中央欄位由數量改為價格資料。

```text
名稱       進價     售價
小S包      10.0    12.5
小O包      12.0    14.0
...
```

| 欄位 | 說明 |
| --- | --- |
| 名稱 | 產品簡稱。 |
| 進價 | `product.purchase_price`，只作為參考顯示，不能在客戶訂單畫面修改。 |
| 售價 | 特定客戶售價，可修改；資料寫入 `customer_product.sale_price`。 |

右側功能鍵：

| 按鍵 | 行為 |
| --- | --- |
| `Esc` | 回跳。 |
| `F3` | 進入/離開售價模式。 |
| `0` | 更改數量。 |
| `\` | 更改售價。 |
| `F1` | 增加產品。 |
| `F2` | 計算檢查。 |
| `F3` | 順序檢查。 |
| `F9` | 刪除產品。 |
| `Alt+A` | 螢幕切換。 |
| `Ctrl+Home` | 數量歸零。 |

> 截圖文字顯示「暗鍵 切換 設定售價/新增刪除產品」，表示部分功能鍵不一定在主提示列完整揭露，但需要支援鍵盤操作。

### 產品總數模式

從客戶訂單切換到產品總數後，右側顯示各產品加總數量；左側仍保留客戶交易數。

```text
┌名稱__ 數量_____ 名稱__ 數量_____ 名稱__ 數量_____┐ ┌產品__總數_┐
│ 徐素華                                           │ │ 散腰花     │
│ 甲上                                             │ │ 小S包      │
│ 蘇婉筑 10.                                      │ │ 小O包  10  │
│ ==END==                                          │ │ ...        │
└──────────────────────────────────────────────────┘ └───────────┘
總數 10.0    交易 0.
```

用途：

- 檢查某市場當日所有客戶訂單的產品加總。
- 與「總數核對」畫面交叉比對。

### 總數核對

底部 `4.總數核對` 進入總數核對畫面。

```text
其餘市場   建國市場   南部市場   品名__ 總數量___
0          0          0          甜不辣  0
0          0          0          糯米腸  0
...

F1: 逐一顯示    PgUp/PgDn: 換頁    Esc: 跳出
```

| 欄位 | 說明 |
| --- | --- |
| 其餘市場 | 該產品在其餘市場的總數量。 |
| 建國市場 | 該產品在建國市場的總數量。 |
| 南部市場 | 該產品在南部市場的總數量。 |
| 品名 | 產品簡稱。 |
| 總數量 | 三市場合計。 |

## 3.2 廠商進退貨

### 畫面配置

```text
┌廠商__交易數_┐  ┌品名____ 銷貨____ 進貨____ 退貨____┐  ┌產品資訊────────┐
│ 顯新        │  │ 臭豆腐   0.0      0.0              │  │ 品名: 臭豆腐    │
│ 鉅台        │  │ 臭腐     0.0      0.0              │  │ 其餘: 0.0       │
│ 台一干      │  │ 非豆干   0.0      0.0              │  │ 建國: 0.0       │
│ ...         │  │ == 檔案結束 ==                    │  │ 南部: 0.0       │
└─────────────┘  └────────────────────────────────────┘  │ 銷貨: 0.0       │
                                                        │ 安存: 0.0       │
                                                        │ 進貨: 0.0       │
                                                        │ 昨存:           │
                                                        │ 今存:           │
                                                        │ 退銷比 1:1:16   │
                                                        │ 退貨: 0.0       │
                                                        └────────────────┘
```

### 欄位

| 區塊 | 欄位 | 說明 |
| --- | --- | --- |
| 左側 | 廠商 | 廠商名稱。 |
| 左側 | 交易數 | 該廠商當日有數量的進退貨筆數。 |
| 中央 | 品名 | 產品簡稱。 |
| 中央 | 銷貨 | 當日各市場客戶訂單總銷貨量。 |
| 中央 | 進貨 | 廠商進貨量。 |
| 中央 | 退貨 | 廠商退貨量。 |
| 右側 | 其餘/建國/南部 | 該產品各市場銷貨量。 |
| 右側 | 安存 | 安全庫存。 |
| 右側 | 昨存/今存 | 庫存推算值。 |
| 右側 | 退銷比 | 銷退單位/比例，截圖格式如 `1:1:16`。 |

### 操作

| 按鍵 | 行為 |
| --- | --- |
| `F1` | 增加產品。 |
| `F2` | 檢查。 |
| `F3` | 排序。 |
| `F5` | 列印。 |
| `F9` | 刪除。 |
| `Ctrl+Home` | 進貨歸零。 |
| `End` | 進貨建議。 |
| `0` | 更改進貨。 |
| `\` | 更改退貨。 |
| `*` | 更改昨存。 |
| `Esc` | 回跳。 |

## 重現注意事項

- 舊系統訂單與進退貨都以鍵盤快速操作為核心，滑鼠不是必要操作。
- `Tab` 在客戶訂單畫面是左右區塊切換，不是表單欄位 tab order。
- 客戶訂單中的「客戶交易數」與右側「產品總數」是同一工作畫面的兩種焦點/檢視，不應拆成互不相干的流程。
- 廠商進退貨右側資訊面板是核心功能，需顯示市場銷貨、庫存與退銷比，不只是輸入進退貨數量。
