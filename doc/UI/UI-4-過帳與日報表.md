## 4.0 入口

```text
4.過帳與日報表

作業日期 115年 4月 7日 星期二
0.回主系統  1.過帳  2.日報表
```

| 選項 | 行為 |
| --- | --- |
| `0` | 回主系統。 |
| `1` | 進入過帳流程。 |
| `2` | 進入日報表流程。 |

## 4.1 過帳

```text
4.1 過帳與日報表
過帳

作業日期 115年 4月 7日 星期二
0.回上系統  1.客戶退貨  2.執行過帳
```

| 選項 | 行為 |
| --- | --- |
| `0` | 回上一層。 |
| `1` | 客戶退貨/過帳前退貨資料確認。 |
| `2` | 執行過帳。 |

### 4.1.1 客戶退貨/過帳介面

此畫面用於選擇客戶與品名，查看或輸入退貨資料。截圖中右側表格顯示客戶、品名、退價、退量、金額。

```text
┌客戶選擇────┐ ┌品名選擇────┐ ┌客戶____ 品名____ 退價____ 退量____ 金額____┐
│ 徐素華     │ │ 小S包      │ │ 甲上    小S包    1-0              12.50   │
│ 豆腐嫂     │ │ 小O包      │ │ == 檔案結束 ==                         │
│ 玉香行     │ │ 散S斤      │ └────────────────────────────────────────┘
│ ...        │ │ ...        │
└────────────┘ └────────────┘

客戶: 甲上    品名:         退價:      退量:      金額:
作業日期 115年 4月 7日 星期二
0.回上系統  1.其餘市場  2.建國市場  3.南部市場
```

| 區塊 | 說明 |
| --- | --- |
| 客戶選擇 | 依市場列出客戶，反白目前客戶。 |
| 品名選擇 | 列出產品簡稱，反白目前產品。 |
| 退貨明細 | 顯示客戶、品名、退價、退量、金額。 |
| 底部狀態 | 顯示目前客戶、品名、退價、退量、金額與市場切換。 |

需要確認：

- `退價` 欄位截圖顯示 `1-0`，可能是銷退單位/比例或退價輸入格式，需向舊系統確認。
- 此畫面資料應寫回 `order_table.is_return`、獨立退貨表，或過帳暫存資料，尚未確定。

### 4.1.2 執行過帳

```text
4.1.2 過帳與日報表
執行過帳

過帳對象

完成率:

==> 按 空鍵棒 : 即行過帳 ?    Esc : 取消
作業日期 115年 4月 7日 星期二
0.回上系統  1.客戶退貨  2.執行過帳
```

| 按鍵 | 行為 |
| --- | --- |
| `Space` | 確認並開始過帳。 |
| `Esc` | 取消。 |

過帳畫面需顯示：

- 過帳對象。
- 完成率。
- 確認提示。

資料邏輯待確認：

- 過帳從 `order_draft` 寫入 `order_table`，並建立 `posting_batch` 批次記錄。
- `order_table` 是正式過帳明細，不另寫 `posting` table，也不使用 `posted` 欄位。
- 客戶退貨是否在過帳前併入同一批次。

## 4.2.1.1 列印設定

此畫面用於設定每個市場、每位客戶是否列印日帳單/出貨單。

```text
┌客戶清單────────────┐       ┌按鍵說明────────────────────────┐
│ 徐素華       0.  ○ │       │ Esc: 回跳                      │
│ 豆腐嫂       0.  ○ │       │ 0: 更改開關                    │
│ 玉香行       1.  ● │       │ ●: 印                          │
│ ...              ○ │       │ ○: 不印                        │
└────────────────────┘       │ Alt_組合鍵（以結帳期選定）      │
                             │ F1: 出貨                       │
                             │ F2: 日                         │
                             │ F3: 週                         │
                             │ F4: 旬                         │
                             │ F5: 半月                       │
                             │ F6: 月                         │
                             │ Ctrl_組合鍵                    │
                             │ Home: 本市場全部不印           │
                             │ End: 本市場恢復內定            │
                             │ 內定值                         │
                             │ 出貨單: F1 ~ F6                │
                             │ 日帳單: 僅 F2                  │
                             └───────────────────────────────┘
作業日期 115年 4月 7日 星期二
0.回上系統  1.其餘市場  2.建國市場  3.南部市場
```

### 欄位

| 欄位 | 說明 |
| --- | --- |
| 客戶名稱 | 當前市場客戶。 |
| 交易數 | 客戶當日交易數，截圖顯示如 `0.`、`1.`、`18.`。 |
| 列印狀態 | `●` 表示印，`○` 表示不印。 |

### 操作

| 按鍵 | 行為 |
| --- | --- |
| `0` | 切換目前客戶印/不印。 |
| `Esc` | 回跳。 |
| `Alt+F1` | 依結帳代碼「出貨」選定。 |
| `Alt+F2` | 依結帳代碼「日」選定。 |
| `Alt+F3` | 依結帳代碼「週」選定。 |
| `Alt+F4` | 依結帳代碼「旬」選定。 |
| `Alt+F5` | 依結帳代碼「半月」選定。 |
| `Alt+F6` | 依結帳代碼「月」選定。 |
| `Ctrl+Home` | 本市場全部不印。 |
| `Ctrl+End` | 本市場恢復內定。 |
| `1` / `2` / `3` | 切換其餘市場、建國市場、南部市場。 |

## 重現注意事項

- 第 4 章入口、過帳、日報表都是選單式畫面，底部選項必須與截圖一致。
- 執行過帳是高風險動作，舊系統要求按空白鍵確認，Textual 版也應保留明確確認。
- 列印設定畫面需要顯示每位客戶的列印狀態，並支援批次套用結帳代碼。
- 出貨單畫面目前只有入口截圖，實際列印內容需參考 `doc/FORM.md` 或後續舊系統樣張。
