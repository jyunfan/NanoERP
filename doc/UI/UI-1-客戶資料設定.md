# UI-1 客戶資料設定

來源截圖：`doc/UI-ref/UI-1-客戶資料設定.jpg`

## 用途

維護客戶基本資料。舊 DOS 版同一畫面可依市場切換客戶清單，右側固定顯示結帳代碼說明與功能鍵。

## 欄位

| 畫面欄位 | 對應資料 | 說明 |
| --- | --- | --- |
| 序碼 | 顯示序號 | 畫面排序序號，不等同主鍵。 |
| 代碼 | `customer.id` 或舊系統客戶代碼 | 截圖顯示如 `10.`、`58.`。 |
| 車 | `customer.car_number` | 截圖多為 `0.`，應允許數字輸入。 |
| 名稱 | `customer.name` | 客戶名稱。 |
| 結帳碼 | `customer.checkout_code` | 顯示格式為「代碼. 名稱」，如 `5. 半月`。 |
| 電話(1) | `customer.phone1` | 電話或 `-`。 |
| 電話(2) | `customer.phone2` | 電話或 `-`。 |
| 市場 | `customer.market` | 由底部市場選項決定清單內容。 |

## 結帳代碼

| 代碼 | 名稱 |
| --- | --- |
| 0 | 不印 |
| 1 | 出貨 |
| 2 | 日 |
| 3 | 週 |
| 4 | 旬 |
| 5 | 半月 |
| 6 | 月 |

## 操作

| 按鍵 | 行為 |
| --- | --- |
| 方向鍵 | 移動目前客戶列。 |
| `0` | 更改目前列資料。 |
| `F1` | 增加客戶。 |
| `F3` | 移位，調整客戶顯示順序。 |
| `F5` | 明細列印。 |
| `F6` | 電話列印。 |
| `F9` | 刪除目前客戶。 |
| `Esc` | 回跳上一層。 |
| `0` 底部選單 | 回主系統。 |
| `1` / `2` / `3` | 切換其餘市場、建國市場、南部市場。 |
| `4` | 切換廠商資料。 |

## 重現注意事項

- 畫面應保留 DOS 風格的高亮列：目前列以藍底白字呈現。
- 右側代碼/功能鍵面板是此畫面的一部分，不應藏到說明文件或彈窗。
- 底部必須固定顯示作業日期與市場切換列。
- 截圖中年份為民國年，系統內部可用 ISO 日期，但顯示需支援民國格式。
