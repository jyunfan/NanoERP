## 使用方式

- `SPEC.md` 放整體系統規格與資料邏輯。
- 本目錄放舊 DOS 畫面細節、欄位與按鍵。
- 若 `SPEC.md` 與本目錄衝突，以本目錄的舊 UI 截圖整理為準。

## 鍵盤規格決策

- 舊 DOS 截圖中部分畫面顯示 `Alt_功能鍵`、`Alt_F1` 或 `Alt+F1` 等提示。
- Textual 版統一改為直接按功能鍵，例如 `Alt+F1` 實作與文件皆寫成 `F1`。
- 這是刻意與截圖文字不同的相容性決策：現代終端與 Textual 對 `Alt+Fn` 支援不一致，直接使用 `F1`-`F9` 較穩定，也符合本系統鍵盤快速操作的目標。
- 重新整理或新增 `doc/UI/*.md` 時，若截圖出現 `Alt+<FN>` 或 `Alt_<FN>`，文件與實作仍應寫成 `<FN>`。
