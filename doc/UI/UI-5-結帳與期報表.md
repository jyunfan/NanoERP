## 5.0 入口

第 5 章為結帳、期報表與歷史交易查詢入口。入口截圖反光較重，底部選單可辨識為「查帳」與「列印」。

```text
5.結帳與期報表

作業日期 115年 4月 7日 星期二
0.回主系統  1.查帳  2.列印
```

| 選項 | 行為 |
| --- | --- |
| `0` | 回主系統。 |
| `1` | 進入查帳功能。 |
| `2` | 進入列印功能。 |

需要確認：

- 舊系統主選單與部分文件寫作「結帳與其報表」，本檔依截圖檔名與功能語意整理為「結帳與期報表」。
- 入口截圖的 `1` 字樣因反光可能被誤讀；目前依畫面判讀為 `1.查帳`。

## 5.1 查帳

查帳底下有「進銷明細」與「營業總額」兩個子功能。

```text
5.1 結帳與期報表
查帳

作業日期 115年 4月 7日 星期二
0.回上系統  1.進銷明細  2.營業總額
```

| 選項 | 行為 |
| --- | --- |
| `0` | 回上一層。 |
| `1` | 進入進銷明細查詢。 |
| `2` | 進入營業總額查詢。 |

## 5.1.1 進銷明細

此畫面用於查詢客戶歷史交易。畫面分為左側客戶清單、中央日期交易額、右側品項明細。

```text
┌客戶選擇────┐ ┌────日期────交易額──┐ ┌──品名────數量────金額──┐
│ 徐素華     │ │ 81. 03-22-2026  563 │ │ 1. 粗條    1.0   47.00 │
│ 豆腐嫂     │ │ 82. 03-23-2026    0 │ │ 2. 百葉雞  5.0  215.00 │
│ 玉香行     │ │ 83. 03-24-2026  888 │ │ 3. Q絲斤   4.0  180.00 │
│ 黃太太     │ │ 84. 03-25-2026  229 │ │ 4. == 檔案結束 ==      │
│ 卡如那     │ │ 85. 03-26-2026  620 │ └───────────────────────┘
│ Y潘家      │ │ 86. 03-27-2026  442 │
│ 甲上       │ │ 87. 03-28-2026 3,801│
│ ...        │ │ ...                  │
└────────────┘ └──────────────────────┘

頁數: 0-0
→ Esc: 跳出  PgUp/PgDn: 換頁
作業日期 115年 4月 7日 星期二
0.回上系統  1.其餘市場  2.建國市場  3.南部市場  4.廠商
```

### 區塊

| 區塊 | 說明 |
| --- | --- |
| 客戶選擇 | 顯示目前市場或類別下的客戶，反白目前客戶。 |
| 日期交易額 | 顯示所選客戶的歷史交易日期與該日交易額，反白目前日期。 |
| 品項明細 | 顯示所選客戶、所選日期的品名、數量與金額。 |
| 頁數 | 顯示右側明細或清單的頁碼範圍，截圖為 `頁數: 0-0`。 |
| 底部市場列 | 可切換其餘市場、建國市場、南部市場與廠商。 |

### 欄位

| 欄位 | 說明 |
| --- | --- |
| 客戶 | `customer.name`。 |
| 日期 | 歷史交易日期；截圖同時出現 `2025`、`2026`，不只限於作業日期。 |
| 交易額 | 該客戶當日交易金額合計。 |
| 品名 | `product.short_name`。 |
| 數量 | 該品項在該交易日的銷售數量。 |
| 金額 | 該品項金額，應使用過帳時保存的單價快照計算。 |

### 操作

| 按鍵 | 行為 |
| --- | --- |
| `↑` / `↓` | 移動目前清單游標。 |
| `←` / `→` | 在客戶、日期、明細區塊間切換焦點。 |
| `PgUp` / `PgDn` | 換頁。 |
| `Esc` | 跳出進銷明細，回查帳選單。 |
| `1` | 切換其餘市場。 |
| `2` | 切換建國市場。 |
| `3` | 切換南部市場。 |
| `4` | 切換廠商資料或廠商查詢維度。 |

需要確認：

- `←` / `→` 是否只切換區塊，或也會展開日期/明細。
- `4.廠商` 進入後的畫面與欄位尚無截圖。
- 交易額為含退貨、扣退貨或純銷貨金額，需依舊系統資料確認。

## 5.1.2 營業總額

截圖只顯示入口選項，尚未提供營業總額明細畫面。依選單語意，此功能應彙總指定範圍內的營業金額。

預期資料來源：

- 以過帳後正式資料 `order_table` 為準。
- 依作業日期、結帳區間、市場或廠商維度彙總。
- 金額使用過帳時保存的售價快照，不回頭套用目前產品售價。

預期欄位：

| 欄位 | 說明 |
| --- | --- |
| 市場/類別 | 其餘市場、建國市場、南部市場或廠商。 |
| 日期或區間 | 查詢或結帳統計區間。 |
| 交易數 | 區間內交易筆數或有交易客戶數。 |
| 營業總額 | 區間內金額合計。 |

## 5.2 列印

入口截圖顯示 `2.列印`，但沒有列印子畫面截圖。此功能應用於輸出結帳週期報表或收帳明細單。

結帳區間依客戶 `checkout_code` 決定：

| 代碼 | 名稱 | 區間規則 |
| --- | --- | --- |
| `0` | 不印 | 不產生報表。 |
| `1` | 出貨 | 作業日期當天。 |
| `2` | 日 | 作業日期當天。 |
| `3` | 週 | 待確認。 |
| `4` | 旬 | 待確認。 |
| `5` | 半月 | 1-15 日或 16 日至月底。 |
| `6` | 月 | 當月 1 日至月底。 |

列印內容可參考 `doc/FORM.md` 的「收帳明細單」：

```text
客戶名稱    月-日
品名        數量      價格
粗條        1.0       47.00
百葉雞      5.0      215.00
                    合計 262.00
```

需要確認：

- 列印是否先提供列印者設定，或直接依 `customer.checkout_code` 產生。
- 週、旬的實際日期切分規則。
- 期報表是否包含出貨單、收帳明細單、營業總額表，或另有其他舊系統表單。

## 資料邏輯

進銷明細與期報表都應讀取過帳後正式資料：

- `order_table`：過帳後訂單明細，包含客戶、產品、數量、單價快照、日期與批次。
- `customer`：客戶名稱、市場與結帳代碼。
- `product`：產品簡稱。

金額規則：

- 明細金額 = `order_table.quantity * order_table.sale_price`。
- 日期交易額 = 同一客戶、同一日期所有明細金額加總。
- 區間營業總額 = 所選範圍內所有日期交易額加總。
- 若舊資料缺少 `order_table.sale_price`，才 fallback 到客戶專用售價或產品售價。

日期規則：

- 底部「作業日期」是目前系統工作日。
- 進銷明細中央清單是歷史交易日期，可顯示不同年份與不同月份。
- 期報表列印區間以作業日期推算，並依客戶結帳代碼決定實際起迄。

## 重現注意事項

- 第 5 章不是單純列印流程，也包含歷史查帳。
- 進銷明細必須保留三欄式查詢：客戶、日期交易額、品項明細。
- 市場切換列在進銷明細畫面包含 `4.廠商`，不同於前幾章只到三個市場。
- `PgUp/PgDn` 換頁與 `Esc` 跳出提示要顯示在畫面右下方。
- 截圖中歷史日期顯示西元年格式，如 `03-27-2026`；作業日期顯示民國年格式，如 `115年 4月 7日`。
